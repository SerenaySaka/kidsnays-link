🔑 GitHub bağlantısı Bağlı değil

Değişiklikleri yayınlamak için bir kez GitHub anahtarı (token) girmen gerekiyor. Anahtar sadece bu cihazda saklanır, başka hiçbir yere gönderilmez. Anahtar nasıl alınır?

Anahtar nasıl alınır?
  1. GitHub'da sağ üstteki profil resmine tıkla → Settings
  2. Sol menünün en altında Developer settings → Personal access tokens → Fine-grained tokens
  3. Generate new token'a bas, bir isim ver (örn. link-paneli)
  4. Repository access: Only select repositories → kidsnays-link
  5. Permissions → Contents: Read and write
  6. Generate token'a bas, çıkan kodu kopyalayıp buraya yapıştır
